# پروژه وب من
این پروژه یک وب‌سایت ساده برای نمایش نحوه استفاده از HTML، CSS، و JavaScript است.

هدف از این پروژه، تمرین مدیریت نسخه با استفاده از Git و GitHub و همچنین آشنایی با توسعه وب پایه است.

## ویژگی‌ها
- صفحه خوش‌آمدگویی: پیام خوش‌آمدگویی در صفحه اصلی.

طراحی واکنش‌گرا: استفاده از CSS برای ایجاد ظاهری سازگار با انواع دستگاه‌ها.

عملکرد جاوااسکریپت: ثبت پیام در کنسول مرورگر برای آزمایش اولیه عملکرد اسکریپت.

## ساختار پروژه

index.html: فایل اصلی HTML که ساختار صفحه وب را تعریف می‌کند.

style.css: فایل استایل که ظاهر وب‌سایت را مشخص می‌کند.

script.js: فایل جاوااسکریپت که عملکرد ساده‌ای مانند نمایش پیام در کنسول مرورگر را پیاده‌سازی می‌کند.

## نحوه استفاده
1. پروژه را کلون کنید:
   ```bash
   git clone https://github.com/Maedeh-Sherafat/WebProject.git
   ```
2. وارد پوشه پروژه شوید:
   ```bash
   cd WebProject
   ```
3. فایل `index.html` را در مرورگر باز کنید.

##نحوه مشارکت

اگر تمایل به بهبود این پروژه دارید، می‌توانید به روش زیر اقدام کنید:

این مخزن را فورک کنید.

تغییرات موردنظر را در شاخه‌ای جدید اعمال کنید.

git checkout -b feature/your-feature-name

تغییرات خود را به مخزن فورک‌شده ارسال کنید.

git push origin feature/your-feature-name

یک Pull Request ایجاد کنید تا تغییرات شما بررسی و ادغام شوند.
